# Coverage floors, checked by scripts/coverage.sh on every CI run.
#
# One package per line: import path, a tab, the lowest coverage it may have.
# Floors go up, never down. Raise them with ./scripts/coverage.sh --update after
# a run that adds tests; lowering one is a deliberate act that belongs in a PR
# description, not a quiet edit.
#
# The floors sit a point or two under what the suite reaches, because coverage
# moves a little between platforms and Go versions and a floor that fails on a
# rounding difference teaches people to ignore it.
#
# Not every package is listed. cmd/ccrawl is a main with three lines in it, and
# internal/fakecc is test fixture; a floor on either would measure nothing.
